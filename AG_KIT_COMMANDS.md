# 🚀 Antigravity Kit: Список команд и агентов

Этот файл содержит справочную информацию по установленным инструментам **Antigravity Kit**. Используйте эти команды и агентов для ускорения разработки и повышения качества кода.

---

## 🛠 Слеш-команды (Workflows)

Введите команду в начале вашего запроса, чтобы запустить специализированный процесс.

| Команда | Описание | Когда использовать |
| :--- | :--- | :--- |
| `/brainstorm` | Структурированный мозговой штурм. | Когда нужно обсудить идеи или архитектуру перед реализацией. |
| `/create` | Создание новой функции или целого приложения. | Когда вы начинаете что-то с нуля. |
| `/plan` | Создание детального плана задачи (без написания кода). | Для сложных задач, требующих разбивки на этапы. |
| `/debug` | Системный поиск и исправление ошибок. | Когда код ведет себя непредсказуемо или падает. |
| `/enhance` | Улучшение или расширение существующего кода. | Для рефакторинга или добавления новых возможностей в старый код. |
| `/orchestrate` | Координация нескольких агентов. | Для комплексного анализа задачи с разных сторон (фронтенд, бэкенд, безопасность). |
| `/ui-ux-pro-max` | Создание интерфейсов премиум-уровня. | Когда нужен дизайн «как у Apple» с модной эстетикой. |
| `/test` | Генерация и запуск тестов. | Для обеспечения надежности кода. |
| `/preview` | Управление локальным сервером. | Для запуска проекта и проверки изменений в браузере. |
| `/status` | Проверка статуса проекта и прогресса агентов. | Чтобы понять, на каком этапе находится выполнение задачи. |
| `/deploy` | Процедуры развертывания проекта. | Перед выпуском кода в продакшн. |

## 🤖 Список специализированных агентов

Система автоматически выбирает нужного агента на основе вашего запроса. Вы также можете вызвать их напрямую через `@название-агента`.

| Агент | Специализация | Особенности |
| :--- | :--- | :--- |
| **@frontend-specialist** | UI/UX Разработка | Современный дизайн, анимации, адаптивность, React/Next.js. |
| **@backend-specialist** | API и серверная логика | Node.js, Python, безопасность данных, производительность. |
| **@project-planner** | Менеджмент и планирование | Фокусируется на создании планов и оценке рисков. |
| **@debugger** | Охотник за багами | Анализирует логи, находит коренные причины проблем. |
| **@security-auditor** | Кибербезопасность | Проверяет уязвимости, права доступа и защиту данных. |
| **@database-architect** | Проектирование БД | Оптимизирует схемы, индексы и сложные SQL запросы. |
| **@mobile-developer** | iOS / Android | Flutter, React Native, нативный опыт. |
| **@orchestrator** | Координатор | Управляет другими агентами в сложных задачах. |
| **@performance-optimizer** | Производительность | Ускорение загрузки, оптимизация ресурсов. |
| **@seo-specialist** | SEO и продвижение | Правильные мета-теги, структура и Core Web Vitals. |

---

## 💡 Как это работает?

1. **Авто-выбор**: Просто напишите «Сделай форму входа», и я сам подключу `@frontend-specialist`.
2. **Socratic Gate**: После сложного запроса я задам 2-3 уточняющих вопроса, чтобы не наделать ошибок.
3. **Checklist**: Перед завершением задачи я запущу автоматическую проверку (Security → Lint → Tests → UX).
